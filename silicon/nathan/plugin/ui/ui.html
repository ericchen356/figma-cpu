1Build hardware
Draws the 8 gates, every module and cell/ENGINE on the page "CPU NATHAN" (made if missing).
2Build the OS
Reads the circuit off the canvas, makes one reaction per control, the variables and the lamps, and three frames: the editor (▶ Present opens it), the machine (every gate as a lamp) and the circuit (the drawing, with a button per module). The viewer runs a reaction's actions recursively; on a cold page 1,200 run in one event overflowed its stack. At the default budget of 700 every control is one event; with a smaller one, a longer reaction runs as a few events: its first part, then the next parts from invisible timed overlays. Takes ~5 minutes.
3Self-test
Replays a random user session through the reactions stored in the file and checks registers, screen lines and the editor layers against the editor spec. No Present mode needed.
?Platform tests
Small prototypes that check what your Figma viewer does (action limit, nesting, bubbling, spacers, keys). ▶ Present and pick a flow "NATHAN test …".
